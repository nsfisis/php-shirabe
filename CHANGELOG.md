# Changelog

## v0.2.0 (based on Composer 2.9.7)

* Prebuilt binaries for Linux (x86_64, aarch64) and macOS (aarch64) are attached to GitHub releases.
* More plugins newly work: `composer/installers`, `dealerdirect/phpcodesniffer-composer-installer`, `symfony/runtime`, etc.
* Non-UTF-8 strings (paths, package metadata, process output, etc.) are no longer corrupted.
* Builds and passes the test suite on macOS. It has not been tested in actual use.
* Many bug fixes.


## v0.1.0 (based on Composer 2.9.7)

First release!

Most commands *do* work as Composer. The support for plugins and scripts are currently limited.
