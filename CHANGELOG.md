# Changelog

## Unreleased (based on Composer 2.9.7)

* More plugins newly work: `composer/installers`, `dealerdirect/phpcodesniffer-composer-installer`, `symfony/runtime`, etc.
* Non-UTF-8 strings (paths, package metadata, process output, etc.) are no longer corrupted.
* Builds and passes the test suite on macOS. It has not been tested in actual use.
* Many bug fixes.
